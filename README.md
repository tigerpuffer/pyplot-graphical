# PyPlot 绘图工具

一个用户友好的 GUI 工具，用于使用 Matplotlib 创建各种类型的图表。无需编码！

## 功能特点

- **多种图表类型**：折线图、柱状图、散点图、误差棒图、直方图、饼图和雷达图
- **多数据集支持**：支持 1-7 个数据集，可自定义标签
- **误差棒**：为数据添加误差棒
- **自定义设置**：标题、标签、网格、图例和数值显示选项
- **用户友好界面**：直观的 GUI 界面，带示例数据
- **数值显示**：可选择在图表上显示精确数值
- **颜色控制**：为每个数据集单独设置颜色
- **灵活的输入格式**：支持逗号、空格或换行符分隔的数据输入
- **双页面模式**：基础绘图页面 + 自定义代码页面
- **自定义代码**：支持用户编写Matplotlib代码，实现高级绘图功能
- **预置模板**：提供折线图、柱状图、散点图、饼图、3D图等多种模板
- **AI 智能绘图助手**：支持使用 AI 生成图表代码，支持 OpenAI、Claude、DeepSeek 等多种 AI 服务商
- **Excel 数据导入**：支持读取 Excel 文件数据进行绘图
- **代码导出**：支持导出自定义代码到文件
- **一键导入代码**：可将 AI 生成的代码一键导入到自定义代码编辑器

## 如何使用

### 基础绘图

1. **选择数据集数量**：选择要绘制的数据集数量（1-7）
2. **输入 X 轴数据**：输入用逗号、空格或换行符分隔的类别名称
3. **输入数据集数据**：为每个数据集输入：
   - 标签：数据集的名称
   - Y 轴数据：用逗号、空格或换行符分隔的数值
   - 误差数据：可选的误差值，用逗号、空格或换行符分隔
   - 颜色：为数据集选择颜色
4. **图表设置**：
   - 图表类型：选择您想要的图表类型
   - 标题：输入图表的标题
   - X 轴标签：X 轴的标签
   - Y 轴标签：Y 轴的标签
   - 显示网格：勾选以显示网格线
   - 显示图例：勾选以显示图例
   - 显示数值：勾选以在图表上显示精确数值
5. **绘制图表**：点击 "🚀 一键绘制图表" 按钮生成图表

### AI 智能绘图助手

1. 点击菜单 **工具 → AI 智能绘图助手**
2. （可选）选择 Excel 文件导入数据
3. 在文本框中描述您想要的图表
4. 点击 "生成完整代码" 按钮
5. 点击 "导入到自定义代码" 按钮，代码将自动导入到自定义代码页面
6. 点击 "执行代码" 按钮运行生成的代码

### 自定义代码

1. 切换到 "自定义代码" 标签页
2. 输入或导入 Matplotlib 代码
3. 点击 "执行代码" 按钮运行代码
4. 点击 "导出代码" 按钮保存代码到文件
